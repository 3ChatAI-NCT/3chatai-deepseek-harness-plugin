# 使用指南

[中文](usage.md) · [English](usage.en.md) · [返回产品说明](../README.md)

你提供客户经营目标和业务资料，DeepSeek Harness 利用 3Chat 数据分析并准备触达，3Chat 执行已确认的消息发送，已配置的 Agent 接待客户回复；收件人、最终内容和需要人工介入的业务判断由你决定。

## 先准备 3Chat 空间和回复能力

在 [3Chat 国内站](https://www.3chatai.cn/) 完成业务侧准备，再到 DSH 授权插件。以下说明配置目标；具体入口以你的 3Chat 账号和渠道界面为准。

1. **确定组织／空间。** 使用承载目标客户和业务的空间，确认你的账号可以读取客户与沟通记录，并通过目标渠道发送消息。已有空间直接使用；空间与权限由组织管理员维护。
2. **连接发送和接待渠道。** 确认所需渠道账号已在该空间接通，客户及其沟通记录可见，并确定要使用的发送账号。
3. **准备 Agent 的知识与业务规则。** 在 3Chat 中配置产品资料、常见问题、回复语气，以及优惠权限、投诉等需转交人工的情形和接手人员。需要自主接待时，让负责该渠道的 Agent 启用对应回复能力。
4. **验证回复接待。** 使用业务允许的测试客户，先检查渠道中收到的消息是否交给正确的 Agent、回答是否符合资料，以及需要人工时是否能转交。

这些设置在 **3Chat** 完成。DSH 中的插件负责连接已有能力，当前工具不负责创建空间、接入渠道或修改 Agent 配置。只需要查询和拟稿时，可先完成前两项；要让 Agent 接待回复，再完成后两项。

## 在 DeepSeek Harness 中连接

通过 DSH 插件管理器添加并启用预构建 `.tgz`，打开插件面板，点击“连接 3Chat”，在浏览器登录并授权目标组织账号。缺少安装包时，按[开发说明](development.md)构建。

授权完成后回到面板。可以使用“检查连接”确认服务可用，再在对话中查询一个已知客户。连接状态说明 MCP 已接通；Agent 的回复能力以 3Chat 中的配置为准。

中文界面选择国内服务，其他语言选择海外服务。切换界面语言会切换连接器，两端分别授权；请在当前服务重新确认客户和发送账号。无需在聊天中粘贴访问令牌。

## 完成一轮跟进

在同一个 DSH 对话中逐步提出目标，让名单、草稿和执行结果沿用同一上下文。

**第一步：找客户并了解情况。**

> 找出最近 30 天咨询过、最近 7 天没有沟通的客户，看看他们主要关心什么。先列出名单和依据，不发送消息。

助手按当前服务支持的筛选字段查询，并读取相关上下文。客户意向和原因分析属于基于记录的判断；你可以调整时间、范围或排除对象。筛选字段是否可用以服务的实时接口为准。

**第二步：结合业务资料拟稿。**

> 针对刚才选出的客户，结合我提供的活动介绍分别拟一条跟进消息，保留各自关心的问题。先给我看草稿。

将产品说明、活动条件和可使用的图片提供给 DSH。DeepSeek Harness 生成内容；插件提供客户上下文以及后续上传、发送能力。素材与品牌要求由你提供。

**第三步：确认后发送。**

> 使用刚才确认的名单和文案。先展示每位收件人、发送账号、渠道、正文及附件，等我确认后再发送。

核对预览后明确确认。上传和发送还会触发 DSH 本次执行确认。姓名匹配出多位客户时先选择具体对象；附件使用可访问的最终下载地址，或由插件上传后使用。

**第四步：查看执行结果并接待回复。**

> 查询刚才这批消息的进度，告诉我哪些已处理、哪些需要处理。

助手查询原批次的逐项结果。处理完成不等于客户已读或成交。客户回复后，由 3Chat 中负责该渠道的 Agent 按已有知识和规则继续接待；需要人工时由业务团队接手。

## 常见问题

| 情况 | 下一步 |
|---|---|
| 已连接，但找不到客户 | 检查当前语言选择的服务、组织／空间权限和筛选范围；先用已知客户验证。 |
| 能查询，但发送失败 | 检查所选渠道、发送账号与授权，以及返回的具体错误。使用服务给出的处理建议。 |
| 发出后 Agent 没有回复 | 到 3Chat 检查客户回复所在渠道、Agent 接待配置及回复能力；重新授权插件不会代替这些设置。 |
| 需要重新登录 | 在面板重新连接并完成浏览器授权。 |
| 要断开连接 | 面板断开会移除本设备凭据；要撤销组织侧授权，在 3Chat 中另行撤销。 |

海外 WhatsApp 模板发送的账号及模板要求见[工具接口说明](development.md)。需要接口名称、宿主兼容与构建细节时继续阅读开发说明。
